A newspaper front-page poster summing up the world news of Saturday 21 November 2026 in a single 1024×1024 image.

## What this entry is

`entry.png` is the finished poster. `main.py` is a small standard-library-only Python program that copies `entry.png` to `/output/entry.png`, creating the output folder if it does not exist yet. It draws nothing and takes no arguments — running it twice produces a byte-identical copy.

## How to run it

```bash
python3 main.py
```

The poster is then available at `/output/entry.png`.
